## Shared calculations, platform-specific rendering

Volcano separates hierarchical layout and color calculations from UI. The Kotlin artifacts render Compose UI on Android, iOS, and Desktop. `@taewooyo/heatmap-react` bundles the Kotlin/JS core behind a TypeScript API and renders SVG in React web apps. These are separate UI integrations, not one cross-platform component API.

<Callout type="info">Volcano 2.0 is a breaking release. The former DSL and `Volcano()` composable are not part of this API.</Callout>
