## One model, three platforms

Volcano separates platform-neutral heatmap data and layout from Compose UI. Build an immutable tree with `HeatmapNode`, then render it with `Heatmap` on Android, iOS, or Desktop.

<Callout type="info">Volcano 2.0 is a breaking release. The former DSL and `Volcano()` composable are not part of this API.</Callout>
