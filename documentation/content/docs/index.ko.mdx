## 하나의 모델, 세 가지 플랫폼

Volcano는 플랫폼에 독립적인 히트맵 데이터·레이아웃과 Compose UI를 분리합니다. 불변 `HeatmapNode` 트리를 만든 뒤 Android, iOS, Desktop에서 `Heatmap`으로 렌더링합니다.

<Callout type="info">Volcano 2.0은 호환성이 깨지는 메이저 릴리스입니다. 기존 DSL과 `Volcano()` 컴포저블은 이 API에 포함되지 않습니다.</Callout>
