## 계산 코어 공유, UI는 플랫폼별 제공

Volcano는 계층 레이아웃·색상 계산과 UI를 분리합니다. Kotlin 아티팩트는 Android, iOS, Desktop에서 Compose UI를 렌더링합니다. `@taewooyo/heatmap-react`는 Kotlin/JS 코어를 TypeScript API 뒤에 포함하고 React 웹에서 SVG로 렌더링합니다. UI 통합과 공개 API는 서로 다릅니다.

<Callout type="info">Volcano 2.0은 호환성이 깨지는 메이저 릴리스입니다. 기존 DSL과 `Volcano()` 컴포저블은 이 API에 포함되지 않습니다.</Callout>
