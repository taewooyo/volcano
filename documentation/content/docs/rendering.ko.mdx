---
title: 렌더링
description: 공간에 맞춰 콘텐츠를 줄이고, 셀·색상 정책을 바꿉니다.
---

Volcano는 고정 dp 임계값만으로 콘텐츠를 결정하지 않습니다. 실제 사각형의 너비·높이·면적을 기준으로 작은 셀에서는 보조 텍스트와 로고를 감추고, 충분한 공간이 있는 셀에서만 라벨과 지표를 단계적으로 표시합니다. 이 방식은 휴대폰, 태블릿, 데스크톱의 같은 데이터에 자연스럽게 대응합니다.

기본 셀은 적절한 내부 패딩, 대비가 있는 텍스트, 얇은 구분선을 제공합니다. 도메인에 맞는 의미 색상·셀 콘텐츠가 필요하면 제공된 렌더링 정책과 셀 API로 재정의하세요. 면적은 `value`, 색상은 `metric`이라는 의미를 유지하는 것이 중요합니다.
