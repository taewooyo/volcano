---
title: 로고와 이미지
description: 선택적인 이미지 로더를 사용해 로고를 안전하게 표시합니다.
---

`HeatmapNode.imageUrl`은 nullable입니다. `null`, 빈 문자열, 로드 실패는 오류가 아니라 로고를 표시하지 않는 정상 상태입니다. 따라서 데이터가 일부 로고 URL을 갖지 않아도 기본 모듈에서 예외가 발생하지 않습니다.

기본 `volcano-compose`는 네트워크 이미지 라이브러리를 강제하지 않습니다. Coil을 사용할 앱만 `volcano-compose-coil`을 추가하고 해당 이미지 로더를 주입합니다. 이 분리는 다른 이미지 라이브러리나 사내 캐시를 쓰는 소비 앱의 의존성·크기 부담을 줄입니다.
