## Install

```bash
npm install @taewooyo/heatmap-react
```

The npm package includes Volcano's Kotlin/JS layout and color core. Its peer range accepts React 18.2–18.x and 19.x (including 19.3), while the repository's current development dependency is React 19.2.4; consumers do not need a Kotlin or Gradle toolchain. A future React major is not automatically declared compatible—it must be tested before widening the peer range. React renders SVG; it does not embed Compose UI. The npm package has its own version line (`0.1.0` at initial publication), separate from the Kotlin artifacts.

## Render a heatmap

```tsx
import { Heatmap, type HeatmapNode } from "@taewooyo/heatmap-react";

const market: HeatmapNode = {
  id: "market",
  label: "Market",
  value: 0,
  children: [
    { id: "A", label: "Alpha", value: 60, metric: 4.2 },
    { id: "B", label: "Beta", value: 40, metric: -2.1 },
  ],
};

export function MarketHeatmap() {
  return (
    <Heatmap
      data={market}
      width={960}
      height={480}
      ariaLabel="Market performance"
      metricFormatter={(value) => `${value > 0 ? "+" : ""}${value.toFixed(2)}%`}
      onLeafClick={(node) => console.log(node.id)}
    />
  );
}
```

`width` and `height` are required positive integer SVG dimensions. For responsive layouts, measure the container in the application and pass updated dimensions. `value` controls area; optional `metric` controls the default signed color scale. A group can have `value: 0` when its children supply positive weights. Node IDs must be non-blank and unique among siblings.

## Updates, selection, and navigation

Pass a new immutable `data` tree when feed values change. Mutating an existing tree in place will not invalidate layout memoization. A changed fill color transitions over 240 ms by default; this is a visual transition, not a data-rate limiter. For a fast feed, decide in the application whether to batch incoming updates and profile the chosen dataset and browser.

React exposes `onGroupClick` and `onLeafClick` but does not manage drill-down or breadcrumbs. The application decides which root to show and how Back works. `selectedId` highlights matching leaf IDs; if IDs repeat in different branches, store the callback's `cell.key` and pass it as `selectedKey` for an unambiguous selection. `selectedKey` takes precedence over `selectedId`.

## Rendering and accessibility

The SVG renderer adapts text and optional circular `imageUrl` logos to cell size. Image loading and caching belong to the browser or host application, not the Kotlin core. A leaf tooltip appears after 400 ms of pointer hover or focus by default; touch users need a click or another host-owned detail action. Clickable cells and group headers support Enter and Space. Set `ariaLabel` to describe the chart, and do not rely on color alone to convey meaning.

Use `palette`, `maximumAbsoluteMetric`, and the optional node `color` for color rules. `metricFormatter` affects displayed text, not layout or color. See the [React API Reference](/docs/react-api) for types, defaults, and validation rules.

## Run the web demo

The [React demo](https://github.com/taewooyo/volcano/tree/main/examples/react-demo) has a normal view, a 100 ms fast feed, and aggregated/raw 5,000-leaf modes. It is a manual stress scenario, not a published frame-rate guarantee. To run it from this repository, build the local Kotlin/JS core and package first:

```bash
./gradlew :volcano:jsDevelopmentLibraryCompileSync
cd packages/volcano-react && npm ci && npm run build
cd ../../examples/react-demo && npm ci && npm run dev
```
